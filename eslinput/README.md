# ESL Input Materials

This directory contains materials for English as a Second Language (ESL) learning, specifically for extensive reading.

## Contents

-   **HomoDeus/**: Contains the unpacked e-book "Homo Deus: A Brief History of Tomorrow" by Yuval Noah Harari.
-   **Sapiens/**: Contains the unpacked e-book "Sapiens: A Brief History of Humankind" by Yuval Noah Harari.

## Purpose

These materials are used for extensive reading practice, which is a key component of language acquisition. By reading engaging and comprehensible content, learners can improve their vocabulary, grammar, and overall reading fluency in a natural and enjoyable way.

The unpacked format allows for easy processing and analysis of the text, which can be useful for creating custom learning materials, such as vocabulary lists or sentence mining cards.
