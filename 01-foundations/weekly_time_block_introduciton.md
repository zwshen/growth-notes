
## 1. 基本原則

* **固定總量**：40 小時 = 每週 5 天 × 8 小時
* **切成區塊**：建議用 **time blocks**（1h \~ 2h）而不是隨意的「待辦清單」
* **明確標籤**：每個 block 都要標記用途 → 深度工作 / 例行工作 / 學習成長 / 行政溝通
* **留白緩衝**：每天至少保留 1 block 彈性（應對突發事件）

---

## 2. Block 類型

* 🟢 **Deep Work (專注任務)**：2h 為佳（程式設計、寫報告、分析）
* 🟡 **Shallow Work (例行/行政)**：0.5h–1h（回信、開會、文件處理）
* 🔵 **Collaboration (協作)**：1h（討論、會議、pair work）
* 🟣 **Learning & Growth (學習/反思)**：1h（技能學習、閱讀）
* ⚪ **Buffer (緩衝)**：0.5h–1h

---

## 3. Weekly 40h Time Block Example

### Weekly Layout (5 days × 8h = 40h)

```markdown
# 📅 Weekly Time Block Schedule

## Monday – Friday
- 09:00–11:00 🟢 Deep Work (Project coding / analysis)
- 11:00–12:00 🟡 Shallow Work (Emails, admin)
- 12:00–13:00 Lunch
- 13:00–15:00 🟢 Deep Work (Core tasks)
- 15:00–16:00 🔵 Collaboration (meeting / team sync)
- 16:00–17:00 🟡 Shallow Work (docs, follow-ups)
- 17:00–18:00 🟣 Learning & Growth (skills, reading, reflection)
```

### Weekly Summary

* Deep Work: 20h
* Shallow Work: 10h
* Collaboration: 5h
* Learning: 5h
  \= **40h**

---

## 4. 管理技巧

1. **週一早上**：規劃全週 block，填寫大目標。
2. **每日開始前**：確認今天要守住的 2–3 個 Deep Work block。
3. **每日結束**：快速反思，調整隔天 block。
4. **週五收尾**：檢查實際 vs 計畫，做迭代。

---

## 🛡 守住 Deep Work Blocks 的四個層次

### 1. **制度層（環境約束）**

* **預約式管理**：把 Deep Work block 當成會議，直接放進日曆 → 團隊也會知道你此時段「忙碌」
* **會議隔離**：在團隊週會時，先協調好哪些時段是「不可打擾區」
* **通知隔離**：Slack/Teams 設定自動回覆：

  > "I’m in a focus block until 11:00. Will get back to you after that."

---

### 2. **技巧層（操作細節）**

* **2 分鐘規則**：開始 Deep Work 前，先清理所有「心裡掛著的」小事（回一個快訊息、寫下待辦） → 避免中途想起來被分心
* **專注道具**：番茄鐘、降噪耳機、專注播放清單
* **任務縮小**：每個 Deep Work block 對應到一個具體任務（而不是模糊的「寫報告」→ 改成「完成報告的實驗結果章節草稿」）

---

### 3. **習慣層（自我管理）**

* **固定儀式**：每次 Deep Work 開始前，做相同動作（例：泡一杯茶、關 Slack、打開特定 IDE）→ 讓大腦知道「專注時間要開始」
* **分段檢查**：90 分鐘後快速檢查 → 進展如何？是否需要續上另一個 block？
* **每日回顧**：下班前檢查今天 Deep Work 是否完成，養成「守住它」的成就感

---

### 4. **團隊溝通層**

* **透明化**：告訴同事「我上午 9–11 是專注時間」，讓他們知道這是習慣而非臨時安排
* **建立共識**：如果團隊都有「Focus Hour」，互相尊重 → 成本最低

---

## 🧩 實用守護策略

1. **最少一次上午 Deep Work**：一天至少守住一個上午 2h block → 成為不可動搖的核心產能
2. **Block 必須具名**：不要寫「Deep Work」而已，要標記「Deep Work – Firmware Power Mgmt」
3. **優先排 Deep Work**：先排它，再排會議和雜事 → 不然一定被擠掉
